Docs changes for the Angular guide that a new user hits between install and the first event on v11, from the runtime docs audit (develop `03aaf42455` and `6f2da7483d`, docs `aebda0ee4`). Each item links to its issue draft in the secret gist (https://gist.github.com/JPeer264/6d973a8266700d0cecbca9ed27cf8b21); the reproductions are [`quickstarts/angular/`](<https://github.com/JPeer264/sentry-repros/tree/issue-linear-runtime-improvements/quickstarts/angular>) in the audit repository.

## Must land

- [ ] **P0** · DOC-Q32 · Three snippets do not compile under the tsconfig ng new generates
  `guides/angular/manual-setup.mdx:246-275` (the Angular 19+ tab) calls `inject(TraceService)` at `:270` but imports only `ApplicationConfig`, `ErrorHandler`, `inject`, `provideAppInitializer`, `Router` and `* as Sentry`: `ng build` fails with `TS2304 Cannot find name 'TraceService'`. With `inject(Sentry.TraceService)` the app runs and pageload and navigation segments are named after the route (`/users/:id/`, source `route`).
  `guides/angular/features/error-handler.mdx:67-82` extends `Sentry.SentryErrorHandler` with `handleError(error: any): void` (`:76`) and fails with `TS4114 This member must have an override modifier` under the strict tsconfig `ng new` generates (`noImplicitOverride: true`).
  `guides/angular/features/component-tracking.mdx:80-94` and `:106-122` fail with `TS2304` for `OnChanges`, `SimpleChanges` and `OnDestroy` (only `Component` and `OnInit` are imported), `TS2339 Property 'user' does not exist`, and `NG8001` for the `app-icon` and `app-button` elements the template uses. With the imports and the input added, the trace directive, `TraceClass` and `TraceMethod` all emit their spans.
  **Change:** Call `inject(Sentry.TraceService)` in the app.config snippet. Write `override handleError(error: any): void` in the custom error handler. Import `Input`, `OnChanges`, `OnDestroy` and `SimpleChanges` in the component tracking examples and declare the `user` input the template reads, or trim the template to elements the example defines.
  Draft: [Fix the Angular manual-setup, error handler and component tracking snippets that fail to build](<https://gist.github.com/JPeer264/6d973a8266700d0cecbca9ed27cf8b21#7-fix-the-angular-manual-setup-error-handler-and-component-tracking-snippets-that-fail-to-build>)

## Should land

- [ ] **P1** · DOC-Q33 · No working registration for a subclassed SentryErrorHandler
  `guides/angular/features/error-handler.mdx:62-82` says to extend Sentry's `ErrorHandler` as in the example and shows no registration. Registered as `{ provide: ErrorHandler, useClass: CustomErrorHandler }`, the app never bootstraps: `NG0201` in production, and in development `DEPRECATED: DI is instantiating a token "CustomErrorHandler" that inherits its @Injectable decorator but does not provide one itself` followed by `NG0402`, because the inherited factory injects the unprovided `errorHandlerOptions` token. `{ provide: ErrorHandler, useValue: new CustomErrorHandler() }` boots and reports errors through the subclass.
  **Change:** Show the provider as `useValue: new CustomErrorHandler()` (or a factory that passes the options), and say why `useClass` fails.
  Draft: [Show a working provider for a subclassed SentryErrorHandler on the Angular error handler page](<https://gist.github.com/JPeer264/6d973a8266700d0cecbca9ed27cf8b21#116-show-a-working-provider-for-a-subclassed-sentryerrorhandler-on-the-angular-error-handler-page>)
- [ ] **P1** · DOC-Q34 · The component tracking span ops are named wrong
  `guides/angular/features/component-tracking.mdx:18` and `:56` say the trace directive and `TraceClass` add spans called `ui.angular.init`; `:78` says `TraceMethod` spans are called `ui.angular.[methodname]`. Observed: op `ui.mount` named `<header>`, `<Header>` or `<unnamed>` (origins `auto.ui.angular.trace_directive` and `auto.ui.angular.trace_class_decorator`), and op `function` named `<Login.ngOnChanges>` with `code.function.name: ngOnChanges` for the method decorator, all under the pageload segment. Only `common/migration/v10-to-v11/index.mdx:455` records the rename.
  **Change:** Rename the ops to `ui.mount` and `function`, and state the `<name>` span naming and the `code.function.name` attribute.
  Draft: [Rename the component tracking span ops on the Angular page](<https://gist.github.com/JPeer264/6d973a8266700d0cecbca9ed27cf8b21#117-rename-the-component-tracking-span-ops-on-the-angular-page>)
