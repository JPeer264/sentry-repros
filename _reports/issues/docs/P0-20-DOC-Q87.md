`guides/nextjs/manual-setup/pages-router.mdx:113-128` shows a Turbopack tab and `:140`, `:152` create `sentry.client.config.ts` for the client init. A Next 16 Turbopack build ignores that file silently: the SDK is not in any client chunk, the verify button reaches nothing, and no build warning appears (the deprecation warning exists in the webpack path only). The page also has no `instrumentation.ts`, `register` or `onRequestError` step (`:138-207` create the server and edge config files only); in this run the server SDK initialized only because the App Router page's `instrumentation.ts` was present, and `onRequestError` was what captured every server error, Pages API routes and `getServerSideProps` included.

What to change:

- Use `instrumentation-client.ts` on the Pages Router page and keep `sentry.client.config.ts` for the webpack tab only; add the `instrumentation.ts` step from the App Router page.
