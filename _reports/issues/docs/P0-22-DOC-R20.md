**Note.** owned by Linear SDK-1351 (removal of the custom OpenTelemetry setup page); do not file separately.

Three Bun OpenTelemetry includes are written against a package and APIs that no longer exist. `platform-includes/performance/opentelemetry-setup/javascript.bun.mdx:5` and `:48` import `SentryContextManager, validateOpenTelemetrySetup` from `@sentry/node-core`; `error-monitoring-only/javascript.bun.mdx:3` and `with-custom-sampler/javascript.bun.mdx:3` do the same. `javascript.bun.mdx:12` and `:55` pass `skipOpenTelemetrySetup: true`, `error-monitoring-only/javascript.bun.mdx:30` calls `provider.addSpanProcessor(...)`, `SentrySampler` is constructed at `javascript.bun.mdx:6`, `:26`, `:49`, `:67` and `error-monitoring-only/javascript.bun.mdx:4`, `:27`, and `with-custom-sampler/javascript.bun.mdx:4` and `:13` use `wrapSamplingDecision`.

On develop there is no `node-core` package under `packages/`, a merge the migration guide records at `docs/platforms/javascript/common/migration/v10-to-v11/index.mdx:1396`. `skipOpenTelemetrySetup`, `SentryContextManager`, `validateOpenTelemetrySetup`, `SentrySpanProcessor`, `SentrySampler` and `wrapSamplingDecision` appear nowhere in `packages/*/src`; the only `SentrySampler` string left in the repository is a stale comment in `packages/node/src/integrations/node-fetch/undici-instrumentation.ts` (`:265` at the pin, `:256` on develop). `packages/opentelemetry/src/index.ts` is nine lines and exports only `getScopesFromContext`, `SentryPropagator`, `SentryTracerProvider`, the `AsyncLocalStorageLookup` type, `setOpenTelemetryContextAsyncContextStrategy` and `registerPrepareSpanScope`.

This cannot be repaired by swapping imports. With the sampler, the span processor and the context manager all gone, there is no custom OpenTelemetry setup path left to document for Bun. `enableOpenTelemetrySetup: false` is not a replacement for `skipOpenTelemetrySetup: true` either: it is already the Bun default, since `packages/bun/src/types.ts:21-23` documents `@default false` and Bun's `_init` delegates to `initNode` (`packages/bun/src/sdk.ts:158`), where `packages/node/src/sdk/index.ts:253` applies `options.enableOpenTelemetrySetup ?? false`. There is nothing for a Bun reader to set.

What to change:

- Delete the three `javascript.bun` files under `platform-includes/performance/opentelemetry-setup/`.
- Drop `javascript.bun` from the `supported` list in `docs/platforms/javascript/common/opentelemetry/custom-setup.mdx`, the only page that includes them, so nothing else breaks.
- If that page stays for other platforms, fix its body too: `:35`, `:53` and `:66` name the same removed symbols, and `:122` and `:132` still pass `skipOpenTelemetrySetup: true`.
