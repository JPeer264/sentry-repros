Fresh is absent from the docs. There is no `guides/fresh/` directory, and the only "fresh" hits under `docs/platforms/javascript/` are the ordinary English word (for example `guides/cloudflare/features/agents-sdk.mdx:39`). The Cloudflare framework list at `docs/platforms/javascript/guides/cloudflare/index.mdx:16-23` names Astro, Hono, Hydrogen, Next.js, Nuxt, Remix, SvelteKit and TanStack Start and nothing else.

Verified on the develop line: Fresh 2 on workerd with `compatibility_date: "2026-05-01"` and `compatibility_flags: ["nodejs_compat"]`. Fresh's own Vite plugin emits `_fresh/server.js` whose default export is already `{ fetch }`, so no Cloudflare adapter is needed. Keep `@sentry/cloudflare` and any database driver out of the Fresh SSR bundle via `environments.ssr.build.rollupOptions.external`, then write a separate wrangler entry that wraps Fresh's server with `Sentry.withSentry()` from `@sentry/cloudflare`. For database spans, bundle that wrangler entry yourself with esbuild plus `sentryOrchestrionPlugin()` from `@sentry/server-utils/orchestrion/esbuild`, and point wrangler's `main` at the output.

Works today:

- Per-request isolation, incoming trace continuation, outgoing `fetch` spans with propagation headers, `Sentry.logger` logs, and `db` spans through the esbuild orchestrion build.

Known limits:

- Nothing a route handler, middleware or page component throws reaches Sentry on its own: Fresh's default error handler catches it and returns a 500, leaving only the request span marked `internal_error`. Adding `Sentry.captureConsoleIntegration({ levels: ["error"] })` to the `withSentry` options turns Fresh's own `console.error(error)` into an event, at the cost of reporting every other `console.error`.
- The request span is named from the URL (`static`) or the HTTP method alone (`stream`), never the Fresh route pattern.
- `sentryCloudflareVitePlugin()` does not belong in Fresh's `vite.config.ts`: there is no Cloudflare worker environment for it to instrument.
- `mysql2` cannot run on workerd.

What to change:

- Add `docs/platforms/javascript/guides/cloudflare/frameworks/fresh.mdx` with the wiring above and link it from `guides/cloudflare/index.mdx:16-23`.
- Add the missing-worker-environment caveat to `guides/cloudflare/features/vite-plugin.mdx:13-18`.
