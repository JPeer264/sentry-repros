The Hono guide already treats Cloudflare Workers as a first-class tab: `docs/platforms/javascript/guides/hono/index.mdx:12` names Cloudflare Workers as a supported runtime, `:65-78` tells Workers users to install `@sentry/cloudflare` as a peer dependency they never import, `:129-144` is the "Cloudflare Workers: Enable Node.js Compatibility" Expandable, and `:246-274` shows the `sentry(app, {...})` middleware wiring. Two gaps: the Expandable sets `compatibility_flags: ["nodejs_compat"]` but never `compatibility_date`, and the guide's only database sentence, `:162`, is Node.js-only.

Verified on the develop line: `npm install @sentry/hono @sentry/cloudflare hono`, a `wrangler.jsonc` with `compatibility_date: "2026-05-01"` and `compatibility_flags: ["nodejs_compat"]`, `app.use(sentry(app, { dsn, tracesSampleRate: 1.0 }))` as the first middleware, `export default app`, run with `npx wrangler dev`. For database spans the same app is built through Vite instead: `plugins: [cloudflare(), sentryCloudflareVitePlugin({ autoInstrumentation: false })]` from `@sentry/cloudflare/vite`, with `autoInstrumentation: false` because the Hono middleware already applies `withSentry`.

Works today:

- Unhandled route errors, parameterized route names (`GET /users/:id`, source `route`), per-request isolation, incoming trace continuation, outgoing `fetch` spans with propagation headers, `Sentry.logger` logs.
- `db` spans from a `mysql` query, through the Vite build only.

Known limits:

- A Worker bundled by `wrangler dev`/`wrangler deploy` alone emits no database spans and logs no warning.

What to change on `docs/platforms/javascript/guides/hono/index.mdx`:

- Extend the Expandable at `:129-144` to set `compatibility_date` alongside `nodejs_compat`, matching `platform-includes/getting-started-config/javascript.cloudflare.mdx:5`.
- Add a "Database spans on Cloudflare Workers" subsection after `:274` stating that database instrumentation on Workers is build-time only, showing the Vite config above, and linking to `/platforms/javascript/guides/cloudflare/features/vite-plugin/`.
