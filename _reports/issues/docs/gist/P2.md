## 78. Fix Bun guide hygiene: version floor, Hono install command, breadcrumbs, v7 wording

**Audit item:** DOC-B4 · **Type:** docs-change · **Finding:** Guide hygiene: no Bun version requirement, npm install in the Hono guide, no breadcrumbs page

## 90. Note that the root Pages middleware also spans static asset requests

**Audit item:** DOC-R19 · **Type:** docs-change · **Finding:** Cloudflare Pages middleware snippet does not say the root middleware also spans static asset requests

The Cloudflare Pages setup at `docs/platforms/javascript/guides/cloudflare/index.mdx:161-201` tells the reader to register `sentryPagesPlugin` as the first entry in `onRequest` inside `functions/_middleware.js` (snippet at `:174`). `includes/cloudflare-pages-middleware-intro.mdx` instructs creating that file in the `functions` directory at the project root. Neither says which requests the middleware then handles.

Verified: a root `functions/_middleware.js` runs on every Cloudflare Pages request, static asset requests included. Every asset fetch therefore produces its own span and transaction alongside the app's function routes, which changes both the trace volume and what the reader sees in the performance view.

**What to change**

- Add a note to the Pages setup section stating that a root middleware runs on every request, static assets included.
- Point readers at placing the middleware in a subdirectory when they want only their function routes instrumented.
