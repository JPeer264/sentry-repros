The rewrite-frames includes for all three runtimes show a call that cannot run. `platform-includes/configuration/rewrite-frames/javascript.bun.mdx:6-17`, `javascript.deno.mdx:6-17` and `javascript.cloudflare.mdx:6-17` pass `Sentry.rewriteFramesIntegration` an object literal whose members are TypeScript type annotations — `root: string;`, `prefix: string;`, `iteratee: (frame) => frame;` — inside a fence tagged ```javascript with `tabTitle: JavaScript`.

- Move the per-option descriptions out of the object literal into an Options section.
- Put the Cloudflare example in a `withSentry` or `sentryPagesPlugin` options object instead of `Sentry.init`, and keep the `___SDK_PACKAGE___` import placeholder in the Deno snippet.
