`common/migration/v10-to-v11/index.mdx:715-719` says Koa errors are captured by the integration now, so `setupKoaErrorHandler(app)` is no longer needed. With the direct first-line import that `common/install/esm-without-import.mdx:53-63` documents, the orchestrion callback channel never fires and without the call no Koa error reaches Sentry at all: only the sentinel arrived and Koa logged the errors to stderr. That page says only that framework spans are lost.
