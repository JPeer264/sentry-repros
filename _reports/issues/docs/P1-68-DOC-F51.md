Verified on the develop line: SolidStart 1.3 with the `cloudflare-module` Nitro preset, `compatibility_date: "2026-05-01"`, `compatibility_flags: ["nodejs_compat"]`. `@sentry/solidstart` itself does not run on Workers, so keep it for the browser and wire the server side by hand: set `server: { preset: 'cloudflare-module', rollupConfig: { external: ['@sentry/cloudflare'] } }` in `app.config.ts` so Nitro does not inline a second SDK copy, then write a `worker.mjs` that wraps the built Nitro handler with `Sentry.withSentry()` from `@sentry/cloudflare` and point wrangler's `main` at that wrapper. Add a Nitro server plugin registered through `server.plugins` that forwards Nitro's `error` hook to `Sentry.captureException`, otherwise thrown server errors never become events.
