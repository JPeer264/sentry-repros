Proposed issue docs-change

State the Express major the async tracing verify snippet needs, or make it work on Express 4

Description

platform-includes/getting-started-verify/javascript.express.mdx:36-47 replaces the /debug-sentry route with an async handler that throws inside Sentry.startSpan. On express 4.22.2 the request never gets a response (the client timed out, status 000) and the error arrives as auto.node.onunhandledrejection, not through the Express error path; the request segment reports status ok with http.response.status_code: 200 although nothing was sent. On express 5.2.1 the same snippet answers 500 and the error is captured as auto.http.express. The guide names no Express major; the registry's express is 5.

What to change:

  • Say that the async snippet needs Express 5, or add a try/catch that calls next(err) so it works on Express 4 as well.
