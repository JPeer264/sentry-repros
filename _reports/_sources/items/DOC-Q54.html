DOC-Q54The Hono tracing verify snippet uses Sentry without importing it, and the package root exports nothingP1proven

Proposed issue docs-change

Add the runtime import to the Hono tracing verify snippet

Description

platform-includes/getting-started-verify/javascript.hono.mdx:36-47 tells the reader to call Sentry.startSpan in the /debug-sentry route. No Hono snippet imports Sentry into the app file: guides/hono/index.mdx:264-267 imports only { sentry }, and :71 says @sentry/node is not imported directly. Pasted verbatim the route throws ReferenceError: Sentry is not defined, captured as the error, with no test span. import * as Sentry from "@sentry/hono" does not help: the package root exports nothing, and the route throws TypeError: Sentry.startSpan is not a function. With import * as Sentry from "@sentry/hono/node" the snippet works.

What to change:

  • Add the per-runtime import (@sentry/hono/node, /cloudflare, /bun, /deno) to the tracing verify snippet, and say that the package root exports nothing.
