DOC-R20Bun OpenTelemetry setup includes import @sentry/node-core and call APIs that no longer existP0verified in source

Proposed issue docs-change

Rewrite the Bun OpenTelemetry setup includes against develop

Description

Three Bun OpenTelemetry includes are written against a package and APIs that no longer exist. platform-includes/performance/opentelemetry-setup/javascript.bun.mdx:5 and :48 import SentryContextManager, validateOpenTelemetrySetup from @sentry/node-core; error-monitoring-only/javascript.bun.mdx:3 and with-custom-sampler/javascript.bun.mdx:3 do the same. javascript.bun.mdx:12 and :55 pass skipOpenTelemetrySetup: true, and error-monitoring-only/javascript.bun.mdx:30 calls provider.addSpanProcessor(...).

On develop there is no node-core package under packages/. skipOpenTelemetrySetup, SentryContextManager, validateOpenTelemetrySetup and SentrySpanProcessor appear nowhere in packages/*/src. @sentry/opentelemetry exports only getScopesFromContext, SentryPropagator, SentryTracerProvider, setOpenTelemetryContextAsyncContextStrategy and registerPrepareSpanScope (packages/opentelemetry/src/index.ts:1-9). The Bun option is enableOpenTelemetrySetup (packages/bun/src/types.ts:23), and addSpanProcessor was removed in OpenTelemetry JS 2.x.

What to change

  • Drop every @sentry/node-core import and the removed symbols.
  • Replace skipOpenTelemetrySetup: true with enableOpenTelemetrySetup: false.
  • Replace provider.addSpanProcessor(...) with the constructor's spanProcessors array.
