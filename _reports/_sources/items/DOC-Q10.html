DOC-Q10The documented tracePropagationTargets value drops trace headers on 127.0.0.1P2proven

Proposed issue docs-change

Say on the browser config page that the sample tracePropagationTargets matches localhost only

Description

platform-includes/getting-started-config/javascript.mdx:46 sets tracePropagationTargets: ["localhost", /^https:\/\/yourserver\.io\/api/] and presents it as the value for local development.

Observed on develop: the same page served on http://localhost sends sentry-trace and baggage on its fetch; served on http://127.0.0.1 it creates the http.client span but sends no headers, because the string "localhost" does not match the IP form.

What to change:

  • Say that the sample matches the string localhost only, and show 127.0.0.1 or a regular expression for readers whose dev server is reached by IP.
