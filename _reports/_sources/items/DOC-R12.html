DOC-R12Bun feature flag page offers only the generic integration; @sentry/bun exports five providersP1verified in source

Proposed issue docs-change

Enable the provider feature flag pages for Bun

Description

platform-includes/feature-flags/evaluation-tracking-index/javascript.bun.mdx:1 offers Bun readers only "the generic featureFlagsIntegration". The four provider pages each exclude Bun explicitly: launchdarkly.mdx:7, openfeature.mdx:7, statsig.mdx:7 and unleash.mdx:7 list javascript.bun under notSupported.

On develop @sentry/bun re-exports all of them. packages/bun/src/index.ts:176-182 exports launchDarklyIntegration, buildLaunchDarklyFlagUsedHandler, openFeatureIntegration, OpenFeatureIntegrationHook, statsigIntegration, unleashIntegration and growthbookIntegration from @sentry/node. The Deno and Cloudflare exclusions are correct: Deno exports only featureFlagsIntegration (packages/deno/src/index.ts:95), Cloudflare that plus growthbookIntegration (packages/cloudflare/src/index.ts:100-101). Growthbook has no page anywhere in the docs tree.

What to change

  • Remove javascript.bun from the notSupported lists on the four provider pages.
  • Link those pages from the Bun evaluation-tracking include.
  • Add growthbook coverage for Bun and Cloudflare.
