Proposed issue docs-change

Document that errors inside ctx.waitUntil() are not captured

Description

The Cloudflare guide's waitUntil() section at docs/platforms/javascript/guides/cloudflare/index.mdx:372-420 is titled "Spans in waitUntil()" and covers span capture only: the static lifecycle snapshotting the transaction at :378, traceLifecycle: "stream" at :380-382, and forceTransaction: true at :384. Errors are never mentioned, and the sample at :389-416 shows deferred work with no note about failure.

Verified on both trace lifecycles: an error thrown or a promise rejected inside ctx.waitUntil(promise) is never captured. The SDK's waitUntil handling in packages/cloudflare/src/flush.ts and packages/cloudflare/src/client.ts:280-295 is flush and invocation bookkeeping; no error-capture path is attached to it.

What to change

  • Add a sentence stating that errors thrown or rejected inside ctx.waitUntil() are not captured on either trace lifecycle.
  • Retitle the section so it does not read as complete waitUntil coverage.
