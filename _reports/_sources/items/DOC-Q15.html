Rename the Profiler span ops on the React component monitoring page

Description

guides/react/features/component-monitoring.mdx:34-46 and :66-72 say the Profiler generates spans with the ops ui.react.mount, ui.react.render and ui.react.update, attached to the current active transaction.

Observed with withProfiler(App): spans named <App> arrive with the ops ui.mount, ui.update and ui.render (attribute ui.component_name: App, origin auto.ui.react.profiler), as children of the pageload segment span. The v10-to-v11 page records the rename at common/migration/v10-to-v11/index.mdx:454; this page does not.

What to change:

  • Rename the three ops on the page, and say the spans attach to the active root span rather than a transaction.
