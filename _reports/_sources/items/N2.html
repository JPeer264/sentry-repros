N2Importing @sentry/deno before the library does not block injectionnot reproduced

A first probe showed runtime: [] after await import('mysql') when @sentry/deno was imported first. The cause was the probe: mysql loads its instrumented lib/Connection.js on createConnection(), so the marker stays empty until the first connection. With that call (probes/D-HOOK2.mjs) the documented order (hook, SDK import, init(), library) injects on deno 2.9.0 and 2.8.3 (probes/results/D-HOOK.txt).
