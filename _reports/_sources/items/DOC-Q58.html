DOC-Q58The NestJS ESM install page's start script is not a runnable commandP0proven

Proposed issue docs-change

Replace the NestJS ESM start script with a command that runs

Description

guides/nestjs/install/esm.mdx:33-36 shows "start": "--import ./instrument.mjs nest start". Executed as an npm script it fails with sh: --: invalid option: the line names no node binary, and nest start does not accept --import. The NODE_OPTIONS form at :41 works, as does node --import ./dist/instrument.js dist/main.js.

What to change:

  • Show a real command such as node --import ./instrument.mjs dist/main.js, or lead with the NODE_OPTIONS form.
