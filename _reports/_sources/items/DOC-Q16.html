Proposed issue docs-change

Move the React guide routing snippet to the version-agnostic React Router API

Description

guides/react/index.mdx:242-264 wires tracing with Sentry.reactRouterV7BrowserTracingIntegration({ useEffect, useLocation, ... }) and wrapCreateBrowserRouterV7. It works (pageload and navigation segments named /users/:userId), but the develop build marks both, and every other *V6 and *V7 export, @deprecated in build/types/index.d.ts in favor of reactRouterBrowserTracingIntegration and wrapCreateBrowserRouter, which guides/react/features/react-router/v8.mdx:7-66 documents and which behaved the same on react-router 7.18.3 and 8.3.1. There is no runtime warning. The @sentry/react/react-router subpath with a hook-less reactRouterBrowserTracingIntegration() is undocumented.

What to change:

  • Switch the guide snippet to the version-agnostic API and mention the @sentry/react/react-router subpath.
