DOC-Q75The Effect metrics layer breaks the whole program on Effect v3P0proven

Proposed issue docs-change

Drop the metrics layer from the Effect v3 snippet, or say it needs Effect v4

Description

guides/effect/index.mdx:111-115 (the v3 Server tab with the metrics option) merges Sentry.SentryEffectMetricsLayer into the layer. With effect 3.22.2 the layer fails to build with Service not found: effect/Scope, the program never runs and nothing is sent; with effect 4.0.0-rc.112 the same layer builds. The metrics option (:27) also has no verify section.

What to change:

  • Drop the metrics layer from the v3 snippet or state that it needs Effect v4, and add a metrics verify snippet or remove the option until it works on both majors.

Source: runtime docs audit, item DOC-Q75, quick start QS-effect, variants metrics and v4

What ran: Effect getting-started reproduction on 2026-09-09, develop 03aaf42455 (@sentry/effect 10.67.0, one integration installed), effect 3.22.2 and 4.0.0-rc.112, Node 26.5.0: quickstarts/effect, results-*.json per variant.
