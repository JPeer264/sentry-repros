Fix the extensionless instrument import on the Express and Fastify guides and the esm-without-import page

Description

platform-includes/getting-started-use/javascript.express.mdx:22 starts the ESM app with import "./instrument";, while the config step creates instrument.mjs. Node ESM does not probe extensions: the app never starts, Error [ERR_MODULE_NOT_FOUND]: Cannot find module .../instrument ... Did you mean to import "./instrument.js"?. With import "./instrument.mjs" the same app produces exactly the --import output. The same extensionless import sits at common/install/esm-without-import.mdx:55, and the orphaned platform-includes/getting-started-add-top-level-import/javascript.express.mdx imports ./instrument.js. The Fastify tab has the same defect at platform-includes/getting-started-use/javascript.fastify.mdx:20, with the same ERR_MODULE_NOT_FOUND (QS-fastify, variant esm-tab).

What to change:

  • Import ./instrument.mjs in both ESM tabs, matching the file the config step creates, and fix esm-without-import.mdx:55 the same way.
