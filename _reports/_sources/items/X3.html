Add a runtime-by-framework support matrix for Bun, Deno and Cloudflare

Description

There is no page comparing framework support across Bun, Deno and Cloudflare. Framework support is documented today only in the Hono guide (four runtimes), the Elysia guide, and the Cloudflare framework pages. The Cloudflare integrations table at platform-includes/configuration/integrations/javascript.cloudflare.mdx:5-17 is missing four rows the SDK installs - conversationIdIntegration, httpServerIntegration, consoleIntegration and spanStreamingIntegration - and two of its existing rows are wrong: :8 names inboundFiltersIntegration where the SDK installs eventFiltersIntegration, and :17 marks honoIntegration auto-enabled although it is removed on develop.

What was observed across 51 verified framework and runtime cells on develop: 50 of the 51 combinations run. Hono, Astro, React Router and TanStack Start pass every capability on Cloudflare with the documented wiring. Every framework SDK runs on Bun and on Deno, with the wiring recorded in the per-framework items DOC-F1 to DOC-F51. Express, Koa, Hapi and NestJS run on Cloudflare Workers behind the enable_nodejs_http_server_modules compatibility flag. Fastify on Cloudflare Workers is the one combination that does not run. Outgoing fetch is not instrumented on Deno in any framework. The Cloudflare default set is packages/cloudflare/src/baseSdk.ts:51-72 (dedupe, eventFilters, functionToString, conversationId, linkedErrors, fetch, httpServer, requestData, console, plus the registered channel subscribers) with spanStreamingIntegration added by packages/core/src/server-runtime-client.ts:56.

What to change:

  • Add a runtime-by-framework matrix page with one row per framework and one column per runtime, each supported cell linking to the framework page or section for that runtime.
  • Mark Fastify on Cloudflare as not supported, and note the Deno outgoing-fetch limit once, above the table.
  • Add the four missing rows to the Cloudflare integrations table, rename :8 to eventFiltersIntegration, and drop the honoIntegration row at :17 with the integration (DOC-C5).
