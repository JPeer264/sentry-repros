DOC-R11rewrite-frames snippets for Bun, Deno and Cloudflare are TypeScript types inside a JavaScript callP1verified in source

Proposed issue docs-change

Replace the invalid rewriteFrames options snippets with runnable code

Description

The rewrite-frames includes for all three runtimes show a call that cannot run. platform-includes/configuration/rewrite-frames/javascript.bun.mdx:6-17, javascript.deno.mdx:6-17 and javascript.cloudflare.mdx:6-17 pass Sentry.rewriteFramesIntegration an object literal whose members are TypeScript type annotations — root: string;, prefix: string;, iteratee: (frame) => frame; — inside a fence tagged ``javascript with tabTitle: JavaScript`.

Copied as shown, this throws a SyntaxError in every runtime: string is an undefined identifier being used as a value, and the semicolons are not valid inside an object literal. The integration itself works and is exported everywhere the include renders — packages/bun/src/index.ts:194, packages/deno/src/index.ts:79, packages/cloudflare/src/index.ts:82 — so only the snippet is at fault.

What to change

  • Rewrite the three snippets as a runnable call with concrete values, for example a real root path and prefix string.
  • Move the per-option descriptions out of the object literal into an Options section.
