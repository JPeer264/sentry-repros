Import withSentryConfig from @sentry/nextjs/config in every Next.js config snippet

Description

guides/nextjs/manual-setup/index.mdx:91 (and :304, :350, pages-router.mdx:84, :115, :250, :432) imports withSentryConfig from @sentry/nextjs. On develop next build fails at config load with TypeError: (0 , _nextjs.withSentryConfig) is not a function; the export lives on the @sentry/nextjs/config subpath only. With that import the App Router page works end to end on Next 16 with Turbopack: the tunnel route, the verify button, logs, replay, the feedback widget, pageload and navigation segments, route-named server segments, every server error through onRequestError, and trace propagation from the browser through the server to a downstream request.

What to change:

  • Change the import to @sentry/nextjs/config in all seven snippets.
