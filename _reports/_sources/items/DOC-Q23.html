Fix the late-initialization and multiple-apps snippets on the Vue pages

Description

guides/vue/index.mdx:203-219 calls createApp({ template: "<div>hello</div>" }) without importing createApp, and the template option renders nothing (<!---->, no production warning) on the default runtime-only vue export; it works only with the vue/dist/vue.esm-bundler.js alias. With those two fixes addIntegration(vueIntegration({ app })) adds Vue as the twelfth integration and the late app's error carries contexts.vue.

guides/vue/features/multiple-apps.mdx:13-21 calls Vue.createApp(App) with no import; a default import of vue fails on Vue 3, import * as Vue from "vue" works, and then all three apps report errors as auto.function.vue.error_handler with contexts.vue.

What to change:

  • Import createApp and use a render function or an SFC root, or note the full-build alias.
  • Show the import line on the multiple-apps page.
