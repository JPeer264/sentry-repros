DOC-Q55The install pages' Hono config snippets initialize from @sentry/node, which the guide forbidsP1proven

Proposed issue docs-change

Point the Hono config snippets on the CommonJS, ESM and ESM-without-import pages at @sentry/hono/node

Description

guides/hono/index.mdx:168 says to import from @sentry/hono/node, not @sentry/node. The install pages render the opposite: platform-includes/getting-started-config/javascript.hono.mdx:2 and :38 (through common/install/commonjs.mdx:25), common/install/esm.mdx:25 and common/install/esm-without-import.mdx:39 initialize from @sentry/node. Following them, the build prints [Sentry] Sentry was not initialized with @sentry/hono/node and tags every event and span sentry.javascript.node instead of sentry.javascript.hono; the data itself arrives. With @sentry/hono/node the warning disappears and the SDK name is right.

What to change:

  • Point the four Hono config snippets at @sentry/hono/node.
