Say which Next.js errors global-error.tsx and _error.tsx capture and which come from onRequestError

Description

guides/nextjs/manual-setup/pages-router.mdx:223-225 says pages/_error.tsx captures errors during server-side rendering; the getServerSideProps error arrived once through onRequestError (auto.function.nextjs.on_request_error) and captureUnderscoreErrorException skipped it as already captured. manual-setup/index.mdx:244 says global-error.tsx captures errors anywhere in the App Router application; for a throwing server component the client captured only Minified React error #441, and the real error came from onRequestError on the server.

What to change:

  • Describe both components as the client-side fallbacks and point at instrumentation.ts and onRequestError for server errors.
