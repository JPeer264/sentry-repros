Say on the Vue guide that the component context of the verify error appears in production builds

Description

guides/vue/index.mdx:273-298 tells the reader to click the button and find the error. In a development build the error is captured first by BrowserApiErrors without contexts.vue, the Vue error handler's capture is dropped as already captured, and Vue prints Unhandled error during execution of app errorHandler. In a production build the same click is captured once as auto.function.vue.error_handler with the component name and props.

What to change:

  • Add a sentence that the component context and the clean console appear in production builds, and that the dev-mode warning is expected.
