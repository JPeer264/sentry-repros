DOC-F48React Router on Cloudflare: documented noP1proven

Proposed issue new-page

Add a React Router 7 on Cloudflare Workers page

Description

No page documents React Router framework mode on Workers. docs/platforms/javascript/guides/react-router/ holds only index.mdx, manual-setup.mdx and profiling/, and a case-insensitive grep for "cloudflare" across it returns zero hits. In the other direction, docs/platforms/javascript/guides/cloudflare/frameworks/ has no react-router.mdx and the framework list at docs/platforms/javascript/guides/cloudflare/index.mdx:16-23 omits React Router. The nearest page, guides/cloudflare/frameworks/hydrogen-react-router.mdx:188-212, is Shopify Oxygen-specific and prescribes different wiring.

Verified on the develop line: React Router 7.18 in framework mode with SSR, compatibility_date: "2026-05-01", compatibility_flags: ["nodejs_compat"]. Install @sentry/react-router and @sentry/cloudflare (a separate install). react-router.config.ts needs ssr: true and future: { v8_viteEnvironmentApi: true }. vite.config.ts combines cloudflare({ viteEnvironment: { name: 'ssr' } }), reactRouter() and sentryCloudflareVitePlugin() from @sentry/cloudflare/vite. app/entry.server.tsx exports a handleError that calls Sentry.captureException, and wrapSentryHandleRequest supplies the route names.

Works today:

  • Loader errors, parameterized route names (GET /users/:id, source route), per-request isolation, incoming trace continuation, outgoing fetch spans with propagation headers, db spans from mysql through the Vite plugin's build-time instrumentation, Sentry.logger logs.

Known limits:

  • Without the handleError export, React Router routes the throw into the ErrorBoundary and no event is sent.
  • Building with sentryCloudflareVitePlugin({ buildTimeInstrumentation: false }) removes all database spans.
  • mysql2 queries fail on workerd.

What to change:

  • Add docs/platforms/javascript/guides/cloudflare/frameworks/react-router.mdx with the package set, wrangler config, Vite configuration and worker entry above.
  • Add React Router to the framework list at guides/cloudflare/index.mdx:16-23 and a Cloudflare pointer to guides/react-router/index.mdx.

Source: runtime docs audit, item DOC-F48, cell M-reactrouter-cf

Page: docs/platforms/javascript/guides/cloudflare/frameworks/react-router.mdx (new), linked from docs/platforms/javascript/guides/cloudflare/index.mdx:16-23 and from docs/platforms/javascript/guides/react-router/index.mdx

A page must exist for React Router 7 framework mode (SSR) on Cloudflare Workers built with `@cloudflare/vite-plugin`, and it must state that all seven capabilities work — errors, route names, request isolation, incoming trace continuation, outgoing fetch spans, database spans and logs — with no workarounds. It must give the package set (`@sentry/react-router` plus `@sentry/cloudflare`, which is a separate install), the `wrangler` config (`nodejs_compat`, compatibility_date `2026-05-01`), the worker entry wiring, and the Vite configuration combining `@cloudflare/vite-plugin` with the React Router dev plugin. It must also be reachable: add React Router to the framework list on the Cloudflare index and add a Cloudflare pointer to the React Router guide, which currently never mentions the runtime.

Where the docs stand: No page covers this combination. `ls docs/platforms/javascript/guides/react-router/` yields only index.mdx, manual-setup.mdx and profiling/, and `grep -rn -i cloudflare docs/platforms/javascript/guides/react-router/` returns zero hits — the guide is Node-only. In the other direction, docs/platforms/javascript/guides/cloudflare/frameworks/ contains astro.mdx, hono.mdx, hydrogen-react-router.mdx, hydrogen-remix.mdx, nextjs.mdx, nuxt.mdx, remix.mdx, sveltekit.mdx and tanstack-start.mdx — there is no react-router.mdx, and the framework list at docs/platforms/javascript/guides/cloudflare/index.mdx:16-23 omits React Router entirely. The nearest page, docs/platforms/javascript/guides/cloudflare/frameworks/hydrogen-react-router.mdx:188-212, is Shopify Oxygen-specific and prescribes `wrapRequestHandler` from `@sentry/cloudflare/request`, which is not the wiring that worked here.

What ran: React Router 7.18.3 (framework mode, SSR) with @react-router/dev 7.18.3, vite 7.3.6, @cloudflare/vite-plugin 1.54.4 on Cloudflare Workers (wrangler 4.129.0 / workerd 1.20260903.1, local `wrangler dev`), compatibility_date 2026-05-01, nodejs_compat. Cell record.
